* With
** Auto Start
DMS owns autostart (=~/.config/autostart/*.desktop=), not =exec-once=. This
hook starts =hyprland-session.target=, which brings up =dms.service=.

#+begin_src lua
-- DMS_STARTUP_BEGIN
hl.on("hyprland.start", function()
	-- Match XWayland DPI and cursor resources to the active monitor scale.
	hl.exec_cmd(os.getenv("HOME") .. "/.config/hypr/sync-xresources-dpi.sh")
	hl.exec_cmd("dbus-update-activation-environment --systemd --all")
	hl.exec_cmd("systemctl --user start hyprland-session.target")
end)
-- DMS_STARTUP_END
#+end_src

The DMS "Autostart Apps" tab only shows when =xdg-desktop-autostart.target= is
active, and that target is =static= + =RefuseManualStart=yes= — it must be
pulled in with =Wants=. =niri.service= ships this; the DMS-generated
=hyprland-session.target= does not, so add a drop-in (survives regeneration):

#+begin_src conf :tangle ~/.config/systemd/user/hyprland-session.target.d/autostart.conf :tangle no
[Unit]
Wants=xdg-desktop-autostart.target
Before=xdg-desktop-autostart.target
#+end_src

then run =systemctl --user daemon-reload= (never =systemctl --user start
xdg-desktop-autostart.target= directly — it is refused).

[[https://www.reddit.com/r/hyprland/comments/14u9p3v/turning_off_screens_after_locking_them/][Turning off screens after locking them ]]

#+begin_src bash :tangle lock.sh :file-mode (identity #o755) :shebang "#!/usr/bin/bash"
pidof hyprlock || hyprlock &

hyprctl dispatch dpms off
#+end_src

#+begin_src conf :tangle hypridle.conf

    lock_cmd = ~/.config/hypr/lock.sh
    on_lock_cmd = openrgb --noautoconnect -m off
    on_unlock_cmd = openrgb --noautoconnect -m rainbow
}

listener {
    timeout = 600
    on-timeout = loginctl lock-session
}

* Key Bindings
Keybindings are layered: DMS ships the defaults in =dms/binds.lua=, my overrides
live in =dms/binds-user.lua= (git-tracked), and =hyprland.lua= holds only the
game-workspace toggle:

#+begin_src lua
hl.unbind("SUPER + G")
hl.bind("SUPER + G", function()
	local workspace = hl.get_active_workspace()
	local target = workspace and workspace.name == "" and "previous" or "name:"
	hl.dispatch(hl.dsp.focus({ workspace = target }))
end, { description = "Toggle game workspace" })
#+end_src
